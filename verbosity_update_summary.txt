# Summary of Verbosity Level Updates

I've successfully updated the expand_annotation and annotate_grnp functions in grn_table_utils.py to use a 2-level verbosity system as requested:

## Verbosity Levels:
- **verbose=0**: Silent mode - no output
- **verbose=1**: Major steps only - shows progress through main stages
- **verbose=2**: Detailed mode - includes debugging information, intermediate results, and data samples

## Functions Updated:

### 1. expand_annotation()
Updated all print statements to use the new verbosity levels:
- Level 1: Shows major steps (N-terminal, C-terminal, standard GRNs, loops/gaps, completion)
- Level 2: Shows detailed information including:
  - Input data details
  - GRN configuration information
  - Intermediate calculations
  - Missing position details
  - Loop/gap annotation details

### 2. annotate_grnp()
Updated to follow the same pattern:
- Level 1: Shows major workflow steps
- Level 2: Shows alignment details, reference matches, and detailed results

## Example Output:

### With verbose=1:

### With verbose=2:
Includes all of the above plus detailed debugging information like:
- Specific GRN assignments
- Alignment details
- Configuration parameters
- Intermediate calculation results
- Data samples and previews

## Benefits:
1. **Clean output** for normal use (verbose=1)
2. **Full debugging** capability when needed (verbose=2)
3. **Silent operation** for batch processing (verbose=0)
4. **Consistent format** across all GRN processing functions
